Znanje za Spanje — Eleventy + Decap CMS starter
=============================================

Brand: Znanje za Spanje
Coach: Eva

What we added:
- Tailwind CDN + base styles tuned to Soft + Warm + Calm palette
- Homepage, O meni, Storitve, Blog index, Kontakt pages
- Netlify form for contact (no backend required)
- Decap CMS config with site settings, home file, posts, testimonials, services
- Placeholder images (replace with real images in assets/images)
- Sample post

Local development:
1. npm install
2. npm run start
3. Open http://localhost:8080

Deploy to Netlify:
1. Push to GitHub
2. New site on Netlify -> import repository
3. Build command: npm run build, Publish directory: dist
4. Enable Identity and Git Gateway (Site settings -> Identity -> Enable -> Services -> Git Gateway)
5. Visit https://your-site.netlify.app/admin/ to edit content.
